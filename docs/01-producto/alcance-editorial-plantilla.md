# Editorial scope template (per instance)

Do not copy a specific country's politics into the open-source docs. Each deployment defines scope in **`portal/bible/editorial-scope.md`** (created by `./scripts/install-wizard.sh`).

## Starting points

| Type | Purpose |
| --- | --- |
| News | Verifiable recent fact with attribution |
| Analysis | Context; separate evidence from interpretation |
| Opinion | Signed argument; label clearly |
| Tracking | Decision or process over time with states and timeline |

## Product note

The current data model emphasizes **tracking** topics (public cases). News and opinion as first-class article entities are described in the product roadmap; see [roadmap-por-etapas.md](roadmap-por-etapas.md).

For a live example of one deployment's scope, see that instance's public methodology page—not this repository's defaults.
