# Cover images — {{PORTAL_NAME}}

## Rules

- One **16:9** master image per topic (`1600×900` or larger), WebP preferred.
- **No headline burned into the image**—titles render as HTML text.
- Keep the main subject inside the central 80%; leave a calm left zone (~55%) for overlay text.
- Illustration or licensed photo only; do not treat generated art as evidence.
- Upload via MCP **`set_topic_cover`** with `image_base64` or HTTPS `image_url`.

## Palette (defaults)

Use design tokens from `design/tokens.json` unless you overrode CSS variables during branding.

## Agent skill

Install **`resonaria-topic-cover`** from the repository `skills/` folder for step-by-step generation and upload.
