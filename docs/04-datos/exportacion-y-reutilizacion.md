# Exportación y reutilización

## MVP público

- Enlace a ficha y fuentes documentales (URL + localizador).
- Comparador: CSV con período, serie, valor, unidad y referencia de fuente (diseño v3 §16).
- Proteger celdas de texto en CSV contra interpretación como fórmulas en planillas.

## Post-MVP

- Exportación de metadatos de casos y fuentes en JSON-LD o JSON abierto.
- API de solo lectura documentada en OpenAPI para investigación (rate limit).

- Citar URL canónica + fecha de última revisión.
- No presentar propuestas como hechos consumados.
