# Checklist Lanzamiento

> Derivado de [QuePerdimos-plan-de-proyecto.md](../../QuePerdimos-plan-de-proyecto.md) v1.0.

## 18. Checklist de lanzamiento

### Contenido

- [ ] Cada ficha identifica qué existía y qué cambia.
- [ ] Propuestas, normas vigentes y efectos observados están diferenciados.
- [ ] Cifras tienen fuente, fecha, unidad y base comparable.
- [ ] Reemplazos y continuidad parcial fueron investigados.
- [ ] Responsabilidades reflejan documentos y alcance de las votaciones.
- [ ] Justificación oficial y dudas pendientes están presentes.
- [ ] Cada caso tiene responsable y próxima revisión.
- [ ] Las dos fichas piloto se contrastaron con documentos primarios antes de presentarlas como verificadas.

### Producto y operación

- [ ] La lectura móvil funciona sin publicidad ni inserciones sociales.
- [ ] Búsqueda, filtros y fuentes son accesibles.
- [ ] Formularios no publican directamente y tienen protección antispam.
- [ ] Borradores y producción están separados.
- [ ] Existe historial de cambios materiales.
- [ ] HTTPS, acceso administrativo y backups están configurados.
- [ ] Se realizó una restauración de prueba.
- [ ] Metodología, privacidad, responsables y financiamiento son públicos.
- [ ] Se verificaron dominio, URLs y condiciones de proveedores.

### Financiamiento

- [ ] Presupuesto aprobado con costos propios y límites de integraciones.
- [ ] Publicidad desactivable y máximo de un espacio por página.
- [ ] No hay popups, videos automáticos ni anuncios superpuestos.
- [ ] Patrocinios identificados y conflictos evaluados.
- [ ] No se prometen ingresos o métricas sin evidencia.
- [ ] La continuidad inicial no depende de aprobación de AdSense.
- [ ] La plataforma principal de aportes pasó verificación de cuenta, cobro y retiro.
- [ ] Moneda, recurrencia, comisiones y cancelación están claramente informadas.
- [ ] Existe conciliación de aportes y publicación agregada de su uso.
