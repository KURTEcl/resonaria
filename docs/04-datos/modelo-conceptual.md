## 11. Datos y administración

| Entidad | Campos principales |
| --- | --- |
| Caso | ID, slug, título, resumen, área, tipo, estado procedimental, evidencia disponible, efecto observado, fechas, responsable y próxima revisión |
| Programa / institución | Nombre oficial, aliases, organismo, origen, relaciones y componentes |
| Decisión | Tipo de acto, autoría, fecha, boletín o norma, documento y localizador |
| Afirmación | Texto, tipo de afirmación, fuentes, límites, revisor y fecha |
| Fuente | URL, emisor, título, autor, fechas, tipo, localizador y disponibilidad |
| Comparación | Base, valor nuevo, unidades, períodos, cálculo, supuestos y fuente |
| Hito | Fecha, evento, estado asociado y fuentes |
| Noticia | Título, medio, autor, fecha, URL y resumen propio |
| Reacción | Plataforma, URL, autor público cuando corresponda, clasificación y motivo de selección |
| Corrección | Fecha, cambio material, motivo y versión relacionada |
| Aporte | URL/texto recibido, contacto opcional, estado de revisión y plazo de eliminación |
| Patrocinio | Anunciante, pieza, destino, fechas, espacio, monto y declaración de conflicto |

El sistema debe impedir publicar por accidente un borrador de IA. La revisión se registra sobre una versión; cambios materiales posteriores vuelven a revisión. Al corregir cifras o conclusiones, se invalidan también resúmenes y piezas generadas dependientes.

No conservar datos personales innecesarios en versiones públicas. La trazabilidad de contenidos no justifica retener indefinidamente aportes sensibles.
