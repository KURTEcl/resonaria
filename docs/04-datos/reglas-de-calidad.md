# Reglas de calidad de datos

> Complementa [modelo-conceptual.md](modelo-conceptual.md) y [../03-metodologia/protocolo-de-caso.md](../03-metodologia/protocolo-de-caso.md).

## Afirmaciones

- Cada afirmación relevante enlaza a fuente(s) con localizador.
- Tipos: hecho, interpretación, testimonio — no mezclar en un mismo párrafo sin etiquetar.
- Bloquear publicación si: acusación sin respaldo, cifra sin origen, estado contradictorio (salvo ficha limitada explícita).

## Comparaciones presupuestarias

- Misma unidad, año base y perímetro.
- Distinguir propuesta, ley aprobada, vigente, ejecutado.
- No calcular % si base es cero.
- No sumar totales y componentes ni años distintos como una sola pérdida.

## Población

- Separar beneficiarios históricos, población potencial y afectados comprobados.
- No duplicar personas entre fichas sin resolver relaciones.

## Versiones

- Cambios materiales incrementan versión y disparan re-revisión de resúmenes, OG y paquetes de redes.
- Borradores de IA nunca se exponen en API pública.

## Slugs

- Únicos, estables, normalizados; historial para redirecciones 301.
